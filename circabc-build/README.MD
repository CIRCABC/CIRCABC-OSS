# Build CIRCABC on Windows 10 without admin rights

This folder contaions scrpts to help you build CIRCABC on Windows 10 without admin rights

For more information  please read\
[how to set up Setup Development Environment in Windows 10](https://webgate.ec.europa.eu/CITnet/confluence/pages/viewpage.action?spaceKey=MIPS&title=How+to%3A+Setup+Development+Environment+in+Windows+10)

TLDR:

Install from EC Store:

* Intellj IDEA Community Edition (to get maven and JDK)
* Install Node.js 10.15.0 (to get node and npm)
* Insatll VS Code ,Git for Windows 2.22 ...
* Setup environment variables for java , maven node and npm
* Setup proxy for maven git npm

To build CIRCABC use JDK 7\
To build sonar use  JDK 8

For example to build development node 1 execute dev1.bat
