Accessibility statement

This statement applies to content published on the domain: @if(isSCircabc) { https://s-circabc.europa.eu/ } @else { https://circabc.europa.eu/ }.

It does not apply to other content or websites published on any of its subdomains. These websites and their content will have their own specific accessibility statement.

This website is managed by DIGIT A4 and it is designed to be used by as many people as possible, including people with disabilities.

You should be able to:

  • Zoom up to 200% without problems;
  • Navigate most of the website using just a keyboard;
  • Navigate most of the website using a modern screen reader and speech recognition software (on your computer or phone).

This website is designed to comply with the technical standard for websites and mobile apps, EN 301 549, v.3.2.1. This closely follows level ‘AA’ of the Web Content Accessibility Guidelines (WCAG) version 2.1 .

Compliance status

This website is partially compliant with technical standard EN 301 549 v.3.2.1 and the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. See below section ‘Non-accessible content’ for more details.

The website was last tested on December 2025.

Preparation of this statement

This statement was reviewed on October 2024 and it is based on a self-assessment conducted by DG DIGIT, using both automated tools (e.g., WAVE) and manual testing.

Feedback

Compatibility with browsers and assistive technology

The @if(isSCircabc) { S-CIRCABC} @else { CIRCABC } service is designed to be compatible with the following most used assistive technologies:

  • the latest version of Google Chrome, Mozilla FireFox and Microsoft Edge browsers;
  • assistive technologies such as NVDA (Non Visual Desktop Access) and Windows Narrator.

Technical specifications

The accessibility of the @if(isSCircabc) { S-CIRCABC} @else { CIRCABC } service website relies on the following technologies to work with the particular combination of web browser and any assistive technologies or plugins installed on your computer:

  • HTML: for structuring content
  • CSS: for layout and design
  • JavaScript: for interactive elements

Non-accessible content

Despite our best efforts to ensure accessibility of the @if(isSCircabc) { S-CIRCABC} @else { CIRCABC } website, we are aware of some limitations, which we are working to fix. Below is a description of known limitations and potential solutions. Please contact us if you encounter an issue not listed below.

  • 1. Some pages might have poor colour contrast;
  • 2. Some functionalities might not be accessible using only a keyboard;
  • 3. Some heading elements might not be used consistently;
  • 4. Some labels might not be correctly connected with their corresponding form fields;
  • 5. Some images might not have alt text descriptions;
  • 6. Some buttons and/or links might not have readable text;
  • 7. Some error messages are not clearly associated with form controls;
  • 8. Some documents are in PDF format and might not be accessible.
